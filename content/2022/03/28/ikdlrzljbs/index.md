Além de funcionar como ID e ter o BSN e a identificação no mesmo cartão (possivelmente menos cartões na carteira), também da jeito para fazer o ID check no DigiD. Há cada vez mais serviços (principalmente relacionados com saúde) que estão a pedir ID check na app para poder aceder. E a única forma de fazer o ID check é com um ID Dutch (passport, ID card ou drivers license).
