This is a list of the domains I currently own, with a small description of each of them.

<!--more-->

- [**hacdias.com**](https://hacdias.com) - this is the domain you are visiting right now and I use it as my main domain. `hacdias` is also my default handle in the Internet, so you can likely find me with that name.

- [**henriquedias.com**](https://henriquedias.com) - this was my first domain, bought by my father as a gift when I was 14 years old. Nowadays, I redirect it to my main domain. I like to keep it, not just because of emotional attachment, but also because it's my first and last name combined.

- [**h4c.pt**](https://h4c.pt) - this one I bought after [speaking to Sebastiaan](/2021/12/05/h4c-is-live) about it. It's a short domain for a URL shortener. It's short and Portuguese 🇵🇹.

- [**hacdia.sh**](https://hacdia.sh) - this was the domain I used to use for my URL shortener. Right now, it serves the same application as `h4c.pt`. I like to keep it as it combines my handle with `.sh`. Maybe I could use it for code, or some other programming-related thing.

- [**nata.cafe**](https://nata.cafe) - this is the domain of the UNIX server that hosts my website, as well as some other small services for friends and myself. It is an homage to the Portuguese custard tart, Pastel de Nata, and cafés.
