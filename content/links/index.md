## 🛠 Tools {#tools}

- [Boom](https://boom.fyi/) - IPFS link shortener.
- [Textile](https://textile.io/) - set of tools built on IPFS and Filecoin.
- [Wave Share](https://ggerganov.github.io/wave-share) - serverless, p2p, local file sharing with communication through sound.
## 💾 Technologies {#technologies}

- [Hypercore](https://hypercore-protocol.org/) - distributed append-only log protocol.
- [Scuttlebut](https://scuttlebutt.nz/) - distributed social network.
- [IPFS](https://ipfs.io/) - p2p hypermedia protocol.
- [Near Protocol](https://near.org/) - really fast cryptocurrency protocol.
- Web3 Domain Naming Systems
	- [Handshake](https://www.namebase.io/) - you can register your own "TLD" and make subdomains out of it. There's a [DNS](https://www.namebase.io/blog/how-to-access-handshake-domains/) server that you can use to resolve these domains.
	- [ENS](https://ens.domains/)
	- [Unstoppable Domains](https://unstoppabledomains.com/)

## 📚 Educational {#educational}

- [How DNS works](https://howdns.works/) - comics from dnsimple explaining how DNS works. As they say "road trips will never be the same".
- [How HTTPS works](https://howhttps.works/) - comics from dnsimple explaining how HTTPS works.
- [ProtoSchool](https://proto.school/) - a fantastic website with interactive tutorials designed to introduce people to the decentralized web concepts, protocols and tools. There's courses about IPFS, Multiformats, IPLD, Filecoin and Libp2p.
