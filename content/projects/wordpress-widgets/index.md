Between **2015** and **2017**, I developed and maintained three WordPress plugins, in PHP, with [Luís Soares](http://luissoares.com/). These plugins were:

- IMDb Profile Widget [[code](https://github.com/refactors/imdb-widget)] [[plugin](https://wordpress.org/plugins/imdb-widget/)]
- GitHub Profile [[code](https://github.com/refactors/github-profile-widget)] [[plugin](https://wordpress.org/plugins/github-profile-widget/)]
- HackerRank Profile Widget [[code](https://github.com/refactors/hackerrank-profile-widget)] [[plugin](https://wordpress.org/plugins/hackerrank-profile-widget/)]

Facts:

- Required knowledge in PHP, GitHub API, HackerRank API and web page scraping for IMDb.
- Over 7 000 downloads.
