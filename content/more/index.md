## Feeds

All listing pages, such as any category (notes, replies, etc) and any tag have two
feeds attached: a JSON and a RSS one. You can access them by appending `/feed.json`
for the JSON feed, or `/feed.xml` for the RSS feed.

Example for the [notes](/notes) page:

- **Canonical URL**: [https://hacdias.com/notes/](/notes/)
- **RSS feed URL**: [https://hacdias.com/notes/feed.xml](/notes/feed.xml)
- **JSON feed URL**: [https://hacdias.com/notes/feed.json](/notes/feed.json)
