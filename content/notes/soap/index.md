- **Simple Object Access Protocol (SOAP)**
- Defines a message structure
- Uses XML
- Can be used with any transport protocol

![SOAP](/images/soap.svg)

**Disadvantages**

- Forces the use of XML.
- Performance and scalability limited.
- Difficult to implement.
